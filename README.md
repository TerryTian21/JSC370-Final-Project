# JSC370 Final Project: Software Engineering Job Market Analysis

## Overview
This project analyzes the software engineering job market by comparing data from 2021 and 2023. The analysis explores trends in job titles, companies, locations, required skills, and salary predictions using various statistical and machine learning models.

## Key Features
- Comparison of job posting trends between 2021 and 2023
- Analysis of popular job titles and their distribution
- Geographic distribution of job opportunities
- Sentiment analysis of job descriptions
- Salary prediction models using various techniques (Multiple Linear Regression, GLMM, Bagging, XGBoost)

## Technologies Used
- R for data analysis and visualization
- Various R packages including dplyr, ggplot2, tidyr, and syuzhet for sentiment analysis
- Machine learning models for salary prediction
